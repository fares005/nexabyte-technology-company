# Nexabyte Technology Company Website V4

This version adds:
- Interactive Three.js hero
- Loading animation
- Smooth scrolling
- Light/dark mode
- Guided website assistant without API keys
- Service explorer
- 3D tilt cards
- Company timeline placeholders
- Scroll storytelling
- Case-study templates
- Tunisia-only location map
- Insights/blog placeholders
- Careers placeholder
- Animated technology marquee
- Digital skyline footer
- Responsive design
- Firebase Hosting configuration

Important:
- The timeline, case studies, blog posts and careers section deliberately avoid invented claims.
- Replace placeholders only with verified company facts, projects, jobs, screenshots and results.
- A genuine OpenAI-powered assistant requires a secure backend and an API key. Do not place API keys directly in frontend code.

Run:
npm install
npm run dev

Build:
npm run build

Deploy:
firebase init hosting
firebase deploy --only hosting
